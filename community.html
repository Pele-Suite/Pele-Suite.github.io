Pele Community

The Pele-Suite was initially developed under the hospice of the Exascale Computing Project, but is currently community-driven. Users and developers interact mostly via GitHub Discussions. Start with the documentation, then ask questions in the GitHub Discussions of the code you are using.

Documentation and discussions

Use Discussions for questions, ideas and help setting up a case. Use Issues to report bugs.
