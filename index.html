Pele Suite

A suite of adaptive mesh hydrodynamics simulation codes for reacting flows

  • PeleC PeleLMeX PelePhysics PeleAnalysis

What is the Pele Suite?

Pele is a collection of open-source software for simulating reacting flows, from laboratory flames to gas turbines or explosions. The codes share a common physics library and are built on the AMReX adaptive mesh refinement (AMR) framework. The software runs on laptops, CPU clusters as well as GPU-accelerated supercomputers.

The codes

PeleC

Compressible solver for reacting flows. It resolves acoustics and shocks, so it suits high-speed and supersonic combustion, detonations and problems where coupling of the flame with the pressure waves matter.

Documentation GitHub

PeleLMeX

Low Mach number solver for reacting flows, where flow speeds are well below the speed of sound. In this regime, the acoustic time step restriction can be lifted, so it suits turbulent deflagration flames, burners and other subsonic combustion problems.

Documentation GitHub

PelePhysics

The physics library shared by PeleLMeX and PeleC: chemical mechanisms, equations of state, transport properties and chemistry integrators, plus modules for sprays, soot and radiation.

Documentation GitHub

PeleAnalysis

Post-processing tools for the AMReX plotfiles the solvers write, for extracting statistics, surfaces and other quantities from large adaptive mesh datasets.

Documentation GitHub

Which code should I use?

Both solvers use PelePhysics for chemistry and transport. The choice mostly depends on how fast the flow is. The publication page lists recent publications with both solvers as well as a one-sentence description of the topic. Feel free to explore the list for inspiration !

If your problem involves… Start with
laminar flames, turbulent deflagrations, burners, jets and plumes PeleLMeX
Supersonic flows, shocks, detonations, thermo-acoustic, real-gas combustion PeleC
Simulating 0D reactors, exploring new chemical mechanisms or adding new physics models PelePhysics
Analyzing results from either solver with AMReX-native IO and MPI support (large scale runs) PeleAnalysis

History

Pele grew out of more than two decades of work on adaptive mesh refinement and low Mach number combustion at the Center for Computational Sciences and Engineering (CCSE) at Lawrence Berkeley National Laboratory.

1990s: adaptive projection methods

The groundwork was laid by CCSE's adaptive projection methods for variable-density flow (Almgren, Bell, Colella, Howell and Welcome, 1998), the basis of the IAMR code. Pember et al. extended the approach to low Mach number combustion the same year, in what was the first use of local adaptive mesh refinement for unsteady low Mach number combustion (Pember et al., 1998).

2000: LMC

Marc Day and John Bell wrote LMC, a low Mach number combustion code built on CCSE's BoxLib framework (AMReX's predecessor). Its core algorithm, discretely conserves mass and energy with detailed chemistry and transport (Day and Bell, 2000). Over the next fifteen years, supported by DOE's applied mathematics program and SciDAC, LMC was used for laboratory-scale flame simulations as well as highly turbulent canonical flames. In 2012, Nonanka et al. introduced the spectral deferred correction coupling of advection, diffusion and reactions that PeleLMeX still uses today.

2016–2023: the Exascale Computing Project

Under the DOE Exascale Computing Project, LMC was renamed PeleLM in 2017 and transitioned from Boxlib to the new AMReX framework. It was joined by PeleC, a compressible solver whose first version was derived from CCSE's astrophysics code Castro. The Pele codes were rewritten from mixed Fortran and C++ to C++, and were ported to the Exascale machines through AMReX abstraction layer. PeleLM and PeleC were released on GitHub in 2018, along with the shared physics library PelePhysics and the post-processing tools in PeleAnalysis. PeleLMeX, a version of PeleLM without level sub-cycling, was started in 2021 and has now replaced it.

Today

The Pele-Suite is developed by a multi-institution team, led from NREL, with partners at LBNL, Sandia, Oak Ridge, Argonne and Lawrence Livermore and a growing community of users. In 2026, the suite received an R&D 100 Award.
